Manual installation

From download to ready
in six clear steps.

TatkalFill is currently distributed as a ZIP and installed through Developer Mode in Chrome or Edge.

  1. 01

    Download

    Download the latest TatkalFill ZIP file from this website.

  2. 02

    Extract

    Extract the ZIP into a permanent folder on your computer.

  3. 03

    Open Extensions

    Open chrome://extensions in Chrome or edge://extensions in Edge.

  4. 04

    Developer Mode

    Turn on the Developer Mode toggle in the upper-right corner.

  5. 05

    Load Unpacked

    Click Load unpacked and select the extracted extension folder.

  6. 06

    Start Using

    Pin TatkalFill to the toolbar and open it on supported IRCTC pages.

Important

Keep the extracted folder in place. Removing it will make your browser unable to load the extension.

After installation

The correct TatkalFill workflow

Save once, start deliberately, then let TatkalFill continue across the supported booking pages.

  1. 1
    Fill and save

    Enter your login, journey and passenger details in TatkalFill, then press Save.

  2. 2
    Reload IRCTC

    Open or reload the IRCTC train-search page so the latest extension code is ready.

  3. 3
    Press Book

    Open TatkalFill on the IRCTC tab and press Book to start a fresh assisted session.

  4. 4
    Choose language if prompted

    Select English or Hindi. If you already selected a language, TatkalFill continues directly.

  5. 5
    Verify and continue

    TatkalFill fills supported stages through Review Booking. CAPTCHA, OTP, final review and payment stay manual.

Know where details live

Your booking stays under your control.

TatkalFill uses browser extension storage for saved journey and passenger details. The IRCTC password is placed in extension session storage and is cleared when the browser session ends.

  • Autofill starts only after you press Book.
  • Reset removes the details saved by the extension.
  • CAPTCHA, OTP, final review and payment confirmation remain manual.

These statements describe the current extension implementation, not a general security guarantee.

Questions, answered

Everything you need before installing.

Clear answers about setup, storage and what TatkalFill does—and does not—do.

What is TatkalFill?

TatkalFill is a Chrome and Edge extension that saves booking preferences and assists with filling matching fields across supported IRCTC booking pages.

How do I install TatkalFill?

Download and extract the ZIP, open chrome://extensions or edge://extensions, enable Developer Mode, choose Load unpacked and select the extracted extension folder.

Do I need Developer Mode?

Yes. This release is installed manually and currently requires Developer Mode in Chrome or Edge.

Does TatkalFill work in Microsoft Edge?

Yes. TatkalFill works in Microsoft Edge as well as Google Chrome because both support compatible Chromium extensions.

Where are my saved details stored?

Journey and passenger information is saved using local browser extension storage. The password is kept in extension session storage and cleared when the browser session ends.

How do I update the extension?

Download and extract the newest ZIP into a fresh folder, then use Reload for TatkalFill on your browser's extensions page. Confirm your saved details before booking.

Is TatkalFill an official IRCTC product?

No. TatkalFill is an independent third-party extension and is not affiliated with or officially endorsed by IRCTC.
